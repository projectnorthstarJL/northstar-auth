Project North Star

Privacy Policy

Effective date: November 8, 2026

Overview

Project North Star is a personal technology project. This website provides information and authentication support for a personal Google Drive synchronization setup using the third-party GSync plugin for Obsidian.

Google Drive Access

GSync requests Google Drive permissions to synchronize files between a local Obsidian vault and a selected Google Drive folder.

The plugin requests full Google Drive access but is designed to read and modify files only within the folder configured by the user.

Data Storage and Processing

Notes are transferred directly between the user's device and Google Drive. Project North Star does not operate an intermediary server for these transfers.

Authentication credentials are stored locally by the GSync plugin on the user's device. Private notes and authentication credentials are not published through this website.

Data Sharing

Project North Star does not sell Google user data or use it for advertising.

The website is hosted using GitHub Pages, which may process technical information associated with website visits under GitHub's own privacy practices.

Data Retention and Deletion

Synced files remain in the user's local vault and Google Drive until they are modified or deleted through those services or the synchronization plugin.

Users can revoke the application's Google account access at https://myaccount.google.com/permissions and remove locally stored credentials from the plugin.

Third-Party Services

This project uses Google Drive, GitHub Pages, and the independently developed GSync plugin. Project North Star is not affiliated with or endorsed by Google, Obsidian, or the GSync developer.

Changes to This Policy

This policy will be updated if the project's data handling practices change.
